# DecodeLabs Internship – Python Projects
This repository contains Python projects completed as part of my DecodeLabs Internship.
 1. Python To-Do List
-->Description
Python To-Do List is a simple Python program that helps users manage their daily tasks.
-->Features
- Add new tasks
- View all tasks
- Remove tasks
- Simple command-line interface
-->How to Run
Open the terminal in the project folder and type:
python todo.py
If that does not work, type:
py todo.py

2. Expense Tracker
-->Description
Expense Tracker is a simple Python program that allows users to enter their expenses and calculate the total amount spent.
-->Features
- Enter multiple expenses
- Calculate total expenses
- Display total amount spent
- Simple command-line interface
-->How to Run
Open the terminal in the project folder and type:
python expense_tracker.py
If that does not work, type:
py expense_tracker.py
