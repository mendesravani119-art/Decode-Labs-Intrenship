# Expense Tracker
# Description
Expense Tracker is a simple Python project that allows users to enter
multiple expense amounts and calculate the total amount spent.
# How to Run
1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:
python expense_tracker.py
# Example
